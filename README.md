# Python GUI Projects

A collection of small Python projects built using Tkinter. Mostly basic, functional GUI apps — no fancy design, just working code.

## Projects

1. **Stopwatch** (`stopwatch.py`) — Start, stop, and reset a stopwatch with minute/second/millisecond display.
2. **Digital Watch** (`digital_watch.py`) — Live clock showing current time and date, updates every second.
3. **To-Do List** (`todo_list.py`) — Add, mark done, and delete tasks from a list.
4. **File Opener** (`file_opener.py`) — Browse and open any file using the system's default application.
5. **Calendar** (`calendar_app.py`) — Month view calendar with next/previous navigation.
6. **Calculator** (`calculator.py`) — Basic calculator supporting +, -, *, / operations.
7. **Result Calculator** (`result_calculator.py`) — Enter marks for 5 subjects, get total, percentage, and grade.
8. **Folder Organizer** (`folder_organizer_gui.py`) — Select a folder and sort its files into subfolders by type (Images, Documents, Videos, Music, Others).
9. **Pomodoro Timer** (`pomodoro.py`) — 25-minute work / 5-minute break timer with start, pause, and reset.
10. **Slot Machine** (`slot_machine.py`) — Simple slot machine game with spin and win logic.

## Requirements

- Python 3.x
- Tkinter (comes pre-installed with Python on most systems)

## How to Run

Each project is a standalone script:

```bash
python <filename>.py
```

For example:

```bash
python calculator.py
```
